Professional Profile

I'm a backend-focused full-stack engineer with nearly 15 years of software development (full-time since 2011), working mainly in Node.js and TypeScript. I'm currently a Full-Stack Engineer on the Cedars team at LITE-ON Technology, where I handle technical design, backend calculation services and frontend features for an enterprise carbon-management SaaS platform.

Since 2026 I've been building this product with AI coding agents (Claude Code, Codex CLI). I set up MCP servers and command-line tools so the agents can work directly with our project-management system, GitLab and the browser, and I design read-only guardrails and collaboration rules for them.

Outside of work, I build and run two web services of my own, Rental Dispute Lookup and Taiwan Stock Dividends. You'll find them under Portfolio below.
